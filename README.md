<h1>Particle Tracking Diffusion</h1>

<p>
  This repository contains an exercise on the estimation of
  <strong>diffusion coefficients</strong> from single-particle trajectories.
  It uses two-dimensional position measurements to study random walks,
  Brownian motion, and Bayesian inference.
</p>

<p>
  The inferred diffusion coefficient is also used with the
  <strong>Stokes–Einstein relation</strong> to estimate the characteristic
  size of the diffusing particle.
</p>
